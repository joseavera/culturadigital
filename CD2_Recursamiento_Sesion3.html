👤 Identificación
¿Qué son los datos estadísticos?
📐 Idea central
Estadística descriptiva
Es la rama de la estadística que se encarga de recopilar, organizar, resumir y presentar datos de manera comprensible. No predice ni infiere — describe lo que ya ocurrió. Sus herramientas principales son las medidas de tendencia central (que resumen el "centro" de los datos) y las representaciones gráficas (que muestran la distribución visualmente).
📂 Datos cuantitativos
Numéricos
Representan cantidades medibles. Se pueden sumar, promediar y ordenar. Ejemplos: calificaciones, temperatura, nivel de riesgo de una especie (1–5), número de habitantes, precios.
🏷️ Datos cualitativos
Categóricos
Describen características o categorías, no cantidades. No se promedian. Ejemplos: tipo de especie (mamífero, reptil), color, género, nombre de una playa. La moda es la única medida de tendencia central que aplica a este tipo.
🎯 ¿Por qué importa en Cultura Digital?
Datos + herramientas digitales = decisiones informadas
En este propósito formativo usamos hojas de cálculo colaborativas (CryptPad Spreadsheet, Google Sheets) para organizar datos sobre problemáticas reales — especies en peligro, contaminación, uso del celular — y generamos gráficas que comunican visualmente lo que los números solos no muestran con claridad.

Ejemplo real del curso: registrar el nivel de riesgo de 5 especies en una hoja compartida, calcular el promedio con =PROMEDIO() y crear una gráfica de barras para presentarlo al grupo.
Medidas de tendencia central y de dispersión
Medida Tipo ¿Cómo se calcula? Fórmula Aplica a datos…
Media Tendencia central Suma todos los valores y divide entre la cantidad de datos Σx ÷ n Numéricos
Mediana Tendencia central Ordena de menor a mayor y encuentra el valor del centro Posición central Numéricos
Moda Tendencia central Identifica el valor que más se repite Máx. frecuencia Numéricos y cualitativos
Rango Dispersión Resta el valor mínimo al valor máximo Máx − Mín Numéricos
📐
Medida 1
Media aritmética — el promedio
La más usada. Puede verse distorsionada por valores extremos.
x̄ = Σx ÷ n
Σx = suma de todos los valores
n = cantidad de datos
x̄ = media (se lee "x barra")
1Suma todos los valores del conjunto.
2Cuenta cuántos datos hay (eso es n).
3Divide la suma entre n.
📊 Ejemplo

Datos: 4, 6, 8, 10, 12

Suma:4+6+8+10+12 = 40
n =5 datos
Media =40 ÷ 5 = 8
📍
Medida 2
Mediana — el valor central
No le afectan los valores extremos (outliers). Ideal cuando hay datos muy atípicos.
1Ordena los datos de menor a mayor.
2Si n es impar: la mediana es el dato en la posición (n+1)/2.
3Si n es par: la mediana es el promedio de los dos valores centrales.
📊 Ejemplo (n impar)

Datos ordenados: 7, 9, 11, 13, 15

79 11 ← centro 1315
Mediana =11
🔁
Medida 3
Moda — el valor más frecuente
La única medida que aplica también a datos cualitativos. Puede no existir o haber varias modas.
📌 Tipos de moda
Sin moda: todos los valores aparecen una sola vez.
Unimodal: un solo valor se repite más que el resto.
Bimodal: dos valores empatados en frecuencia.
Multimodal: más de dos valores con la misma frecuencia máxima.
📊 Ejemplo

Datos: 3, 5, 3, 8, 9, 3

35 38 93
El 3 aparece3 vecesModa =3
📏
Medida de dispersión
Rango — amplitud del conjunto
No es medida de tendencia central. Muestra qué tan separados están los datos extremos.
R = Máx − Mín
Un rango grande → datos muy dispersos.
Un rango pequeño → datos concentrados.
📊 Ejemplo

Datos: 4, 7, 2, 9, 5

2 ← mín 457 9 ← máx
Rango =9 − 2 = 7
⚠️ Error frecuente — no confundas

El rango NO es una medida de tendencia central. Media, mediana y moda sí lo son. Si la pregunta dice "¿cuál de las siguientes es una medida de tendencia central?" y aparece el rango, la respuesta correcta es alguna de las otras tres.

Tipos de gráficas estadísticas
📌 ¿Para qué sirven las gráficas?

Una gráfica traduce números en imagen. Permite detectar patrones, comparaciones y tendencias que en una tabla de datos son difíciles de ver. Elegir el tipo incorrecto de gráfica puede llevar a interpretaciones erróneas — por eso importa saber cuándo usar cada una.

📊
Gráfica de barras
Compara cantidades entre categorías diferentes. Cada barra representa una categoría.
Cuándo: comparar, frecuencias, resultados por grupo
📈
Gráfica de líneas
Muestra cómo cambia un valor a lo largo del tiempo. Conecta puntos en secuencia.
Cuándo: tendencias, evolución temporal, series de datos
🥧
Gráfica de pastel
Muestra partes de un todo en porcentajes. Útil con pocas categorías (máx. 6).
Cuándo: proporciones, porcentajes, composición de un total
📉
Histograma
Muestra la distribución de frecuencias en intervalos continuos. Sin separación entre barras.
Cuándo: distribución de datos continuos, rangos de edad, peso, temperatura
🛠️ En herramientas digitales
En CryptPad (hoja de cálculo) o Google Sheets: seleccionas los datos → Insertar → Gráfico → eliges el tipo. La herramienta calcula los ejes y la escala automáticamente. Lo importante es elegir el tipo correcto antes de insertar.
📝 Para la evaluación
Cuando te pregunten qué gráfica usar para mostrar cambio en el tiempo → líneas. Para comparar categorías → barras. Para partes de un todo → pastel. Para distribución de datos continuos → histograma.
💡 Fórmulas de hoja de cálculo que debes conocer
Media: =PROMEDIO(H2:H6) Calcula el promedio del rango de celdas
Máximo: =MAX(H2:H6) Encuentra el valor más alto
Mínimo: =MIN(H2:H6) Encuentra el valor más bajo
Rango: =MAX(H2:H6)-MIN(H2:H6) Máximo menos mínimo en una sola fórmula
